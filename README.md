# Responsive Developer Portfolio

CS-554 Advanced Web Technologies, Assignment 1 (Version A).

- **Live site:** https://your-username.github.io/portfolio/
- **Screenshot:** ![Portfolio screenshot](assets/screenshot.png)

## Built with
HTML5, CSS3 (Flexbox, Grid, custom properties) and vanilla JavaScript. No frameworks.

## Features
- 3 pages: Home, Projects, Contact
- Projects rendered from a JS array, with combined search + technology filter
- Dark mode (system preference + toggle, saved in localStorage)
- Contact form with per-field validation
